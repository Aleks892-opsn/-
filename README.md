# REMONT DESIGN — лендинг студии ремонта квартир

Одностраничный адаптивный лендинг: чёрный с золотым акцентом, тонкая антиква Cormorant Garamond
и гротеск Manrope. Правила оформления — в [`DESIGN-SYSTEM.md`](DESIGN-SYSTEM.md).
Чистые HTML/CSS/JS без сборки — откройте `index.html` в браузере.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг (10 секций) |
| `styles.css` | Стили на токенах дизайн-системы (CSS-переменные в `:root`) |
| `script.js` | Меню, карусель портфолио, квиз-расчёт стоимости, анимации, маска телефона, валидация формы, FAQ |
| `privacy.html` | Шаблон политики обработки ПДн (152-ФЗ) |

## Что заменить перед запуском

- **Фото «Почему мы?»** — `images/why-estimate`, `why-warranty`, `why-stages`, `why-report` (`.webp` + `.jpg`).
- **Фото услуг** уже стоят: `images/svc-cosmetic`, `svc-capital`, `svc-design`, `svc-newbuild` (`.webp` + запасной `.jpg`, 4:3).
- **Фото первого экрана** уже стоит: `images/hero.webp` и запасной `images/hero.jpg`. Чтобы заменить — положите свои файлы с теми же именами (лучше от 1600 px по ширине).
- **Фото** — все блоки `.ph` — заглушки с подписью, какое изображение нужно и какого размера.
  Требования к съёмке — в разделе «Фотография» дизайн-системы. Замените `<figure class="ph …">`
  на `<img src="..." alt="..." style="object-fit:cover">` с тем же соотношением сторон.
- **Телефон** `+7 (900) 000-00-00` и `tel:+79000000000`, e-mail, адрес офиса.
- **WhatsApp / Telegram** — ссылки `wa.me/…` и `t.me/…` в подвале.
- **ИНН / ОГРН** — в подвале и в `privacy.html`.
- **Цены в квизе** — атрибуты `value` у ответов первого шага (`name="q-type"`, ₽ за м²) и подписи
  к ним в секции `#calc`; сроки — объект `DAYS` в `script.js`.
- **Чат с менеджером** (кнопка с гарнитурой внизу справа) тоже пока ничего не отправляет.
  Подключите отправку в месте `TODO` в разделе «Чат с менеджером» в `script.js`. Имя «Анна» — условное.
- **Состав работ на обороте карточек услуг** — списки `service__list` в секции `#services`.
- **Отправка квиза** — сейчас ответы и контакты никуда не уходят, квиз только показывает расчёт.
  Подключите отправку в месте `TODO` в обработчике `quiz-form` в `script.js`.
- **Отправка заявки** — сейчас форма только показывает сообщение об успехе.
  Подключите свой обработчик в месте `TODO` в `script.js`.
- **Политика конфиденциальности** — текст-шаблон, проверьте его с юристом.
